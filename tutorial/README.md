# MPAS-A 学习地图

## 怎样使用这套教程

不要把 MPAS 当作“换了网格的 WRF 可执行文件”。每课先尝试用自己的话回答开头问题，
再执行命令，最后只凭输出文件和日志证明结果正确。能向另一个 WRF 用户讲清楚，才算学会。

```text
认知迁移
  ↓
编译器与并行 I/O
  ↓
水平网格 ─→ namelist / streams
  ↓               ↓
GFS → ungrib → static/init → MPAS-A
                              ↓
                       诊断与 Cartopy
                              ↓
               变分辨率 → 有限区域 → DA/Chem
```

## 三个阶段

### 阶段一：先跑通

第 0–7 课使用 240 km 全球网格。它不适合北京精细预报，但文件小、运行快，适合把每个
接口错误单独暴露出来。

### 阶段二：理解 MPAS 的优势

第 8–9 课把 92–25 km 加密中心旋转到北京，并用地图检查网格与预报。这里才真正离开
WRF 的矩形 domain 思维。

### 阶段三：后续专题

在基线和变分辨率案例均通过后，再依次加入周期 SST、restart、有限区域及 LBC、原生
多边形/UXarray、重映射、资料同化和 CheMPASA/MUSICA。完成 MPAS-A 后才进入 E3SM。

## 每课验收模板

1. 输入文件是什么，时间与网格是否匹配？
2. 本步骤只改变了哪些信息？
3. 输出文件中哪个维度、变量或日志能证明成功？
4. 如果换日期、网格或 MPI 数，必须改哪几项？
