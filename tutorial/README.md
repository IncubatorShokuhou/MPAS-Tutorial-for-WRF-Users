# MPAS 课程目录

## 怎样使用这套教程

会设 WRF 区域、跑过 `real.exe` 和 `wrf.exe` 的话，打开 MPAS 最先找不到 `dx`、
`e_we` 和 `wrfbdy_d01`。后面的课从这三处缺口写起。

课末的问题留到做完再看。先读说明，再跑命令，用日志、文件和图对结果。

## 怎样看命令和输出样例

一次操作通常有命令、终端记录，以及目录里新出现或被改过的文件。`bash`
代码块可以复制执行。`console` 是终端记录，`$` 和 `>` 是提示符。`text` 只展示输出或
目录树。后两类不要粘回终端。目录树里 `->` 是软链接，`...` 省掉了路径、重复行或同类
文件。`ls` 样例去掉了和判断无关的用户名、日期。文件大小来自本仓库已经跑通的案例，
只看数量级，不要求每台机器逐字节相同。

文本配置只摘出要核对或要改的几行。NetCDF、GRIB2 和 WPS 中间文件用 `ncdump`、
`rd_intermediate` 看，不要用文本编辑器硬改。“这一步留下了什么”写哪些是输入、哪些是
新文件，以及换日期或换网格时要改哪里。

做 MPAS 初值要同时准备两类资料。`static` 来自 `grid.nc` 和 WPS_GEOG。

```text
grid.nc + WPS_GEOG ─────────→ static.nc ─┐
                                         ├─→ init.nc ─→ MPAS-A ─→ output
GFS GRIB2 ─→ ungrib ─→ FILE:* ──────────┘

graph.info.part.N（网格单元分给 N 个进程）─→ 并行运行
```

## 三个学习阶段

### 第一阶段：先跑通一个小案例

第 0–7 课用粗网格把编译、GFS 解码、初值、积分和读输出走一遍。240 km 做不了北京的
精细预报，但文件小、跑得快，出错时容易看出是哪一步。

### 第二阶段：理解 MPAS 的网格优势

第 8 课把官方 92–25 km 全球网格的加密中心转到北京，并把几何网格、static 和气象初值
分开。第 9 课从全球网格裁区域、做侧边界，再用 JIGSAW 做一张 240–60 km 的自定义网格。
WPS_GEOG 能读了以后，再补变分辨率网格和自定义网格的 static、初值和正式积分。第 10 课
用已经跑通的 240 km 预报画 Cartopy。变分辨率预报做完以后，同一套画法还能接着用。

### 第三阶段：后续专题

还没写成的课有海表温度（SST）定时更新，重启文件接续，用 UXarray 分析原生非结构网格，
守恒重映射，资料同化，以及实验性的大气化学方向 CheMPAS-A/MUSICA。MPAS-A 主线做完，
再进 E3SM、MPAS-Ocean 和耦合模式。

## 每做完一步，都检查这五件事

1. 输入从哪来，时间和网格是否同一套？
2. 改动落在网格、静态地表、天气状态，还是只落在画图？
3. 哪一行日志、哪个维度、哪个变量或哪幅图能证明这一步做成了？
4. 换日期、换网格或改 MPI 进程数时，配置和分区文件要一起动哪些？
5. 哪些数字只属于这个教学案例，哪些对 MPAS 一般都成立？
