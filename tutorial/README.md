# MPAS 课程目录

## 怎样使用这套教程

如果你已经会设置 WRF 计算区域（domain）、跑 `real.exe` 和 `wrf.exe`，刚打开 MPAS 时
多半会有一个疑问：熟悉的 `dx`、`e_we` 和 `wrfbdy_d01` 去哪儿了？这套教程就从这些
疑问讲起。

每课开头的问题用来提醒你“这一课要弄懂什么”，不是让你没学就猜答案。先看解释，再动手
运行；最后对照日志、文件和图检查结果。能把这一步讲给另一位 WRF 用户听，才算真正学会。

## 怎样看命令和输出样例

教程把一次操作分成三块：先给出可以复制的命令，再模拟终端输出，最后列出目录中新出现或
发生变化的文件。标为 `bash` 的代码块可以复制执行；`console` 是终端记录，其中
`$` 和 `>` 是提示符；`text` 只展示输出或目录树。这两类样例都不用粘回终端。目录树中的
`->` 表示软链接，`...` 表示省略了路径、重复输出或同类文件；`ls` 样例也会略去与判断
结果无关的用户名和日期。文件大小来自本仓库已经跑通的案例，只用来判断数量级，不要求
每台机器完全一致。

文本配置会给出需要检查或修改的几行，NetCDF、GRIB2 和 WPS 中间文件则用 `ncdump`、
`rd_intermediate` 等工具查看，不能拿文本编辑器硬改。每个“这一步留下了什么”小节都会说明
哪些文件是输入、哪些是新生成的、下次换日期或网格时应该改哪里。

制作 MPAS 初值要同时准备两类资料。`static` 并不是由 GFS 产生：

```text
grid.nc + WPS_GEOG ─────────→ static.nc ─┐
                                         ├─→ init.nc ─→ MPAS-A ─→ output
GFS GRIB2 ─→ ungrib ─→ FILE:* ──────────┘

graph.info.part.N（网格单元到 N 个进程的分工表）─→ 并行运行
```

## 三个学习阶段

### 第一阶段：先跑通一个小案例

第 0–7 课用粗网格依次验证编译、GFS 解码、初值、模式积分和输出读取。240 km 不适合北京
精细天气预报，但文件小、运行快，出错以后也容易查清是哪一步出了问题。

### 第二阶段：理解 MPAS 的网格优势

第 8 课将官方 92–25 km 全球网格的加密中心旋转到北京，并明确区分几何网格、静态文件和
气象初值。共享 WPS_GEOG 权限解决后，再补做变分辨率初值和正式积分。第 9 课暂时使用
已经跑通的粗网格结果练习 Cartopy，等变分辨率预报完成后，同一套画图方法还可以继续用。

### 第三阶段：后续专题

以下内容是后续计划，还没有写成课程：海表温度（SST）定时更新、重启文件接续、有限区域与侧边界
条件（LBC）、用 UXarray 分析原生非结构网格、守恒重映射、资料同化，以及实验性的大气
化学方向 CheMPAS-A/MUSICA。完成 MPAS-A 主线后才进入 E3SM、MPAS-Ocean 和耦合模式。

## 每做完一步，都检查这五件事

1. 输入文件从哪里来？时间和网格是否对得上？
2. 这一步改的是网格、静态地表、天气状态，还是只改了画图方式？
3. 哪一行日志、哪个维度、哪个变量或哪幅图能够证明它成功了？
4. 如果换日期、换网格或改变 MPI 进程数，还要一起修改哪些配置和分区文件？
5. 哪些结论只适用于这个教学案例，哪些是 MPAS 的一般规律？
